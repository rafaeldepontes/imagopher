# ImaGopher

**ImaGopher** is an image processing API that allows uploading and processing images.

This project was created mainly for learning purposes, but it **does work** and can be used if you want to.

## Security Warning

There is **no login, no authentication, and no access control.**

All uploaded images are publicly accessible.
Anyone can see them. Anyone can download them.

**Do NOT upload personal, private, or sensitive images.**
Never store personal information here. Ever.

If you upload it, assume the whole world can see it — because they can.

You’ve been warned.
